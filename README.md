# 🌿 Bloom - عيادة نفسية متقدمة

## مرحباً بك في موقع عيادة Bloom!

موقع ويب كامل ومتكامل لعيادة نفسية متخصصة، مبني بأحدث التقنيات وبتصميم مريح وآمن للمرضى النفسيين.

### ✨ الميزات الرئيسية

#### 1. **الصفحة الرئيسية (Landing Page)** ✅
- قسم ترحيبي مميز بتصميم حديث
- شريط تنقل واضح وسهل الاستخدام
- عرض تعريفي للأطباء المتخصصين
- أقسام توضيحية للخدمات
- Call-to-Action واضح

#### 2. **التقييم النفسي الذكي (Smart Assessment)** ✅
- استبيان متعدد الخطوات (8 أسئلة)
- اختيار الجنس والعمر
- أسئلة موضوعية تغطي:
  - الاكتئاب والحزن
  - القلق والتوتر
  - الصدمات النفسية
  - الإدمان والتعاطي
- **نظام التوصية الذكي:**
  - إذا كانت الأعراض تشير للإدمان → يقترح د. عمر الفاعوري
  - إذا كانت الأعراض تشير للاكتئاب/القلق/الصدمات → يقترح د. عمر أسعد
  - أولوية عالية للإناث في حالات الاكتئاب/القلق
- حرية كاملة للمريض في قبول التوصية أو اختيار طبيب آخر

#### 3. **نظام حجز المواعيد (Appointment Booking)** ✅
- **الخطوة 1:** اختيار الطبيب من القائمة
- **الخطوة 2:** اختيار التاريخ والوقت
  - تقويم تفاعلي يعرض الأيام المتاحة
  - عرض الأوقات المتاحة والمحجوزة
  - منع الحجز على أوقات محجوزة
- **الخطوة 3:** ملء بيانات المريض (الاسم، البريد، الهاتف)
- **الخطوة 4:** تأكيد الحجز والحصول على رقم موعد فريد

#### 4. **الأمان والخصوصية** ✅
- تشفير بيانات المريض
- حفظ التقييمات بشكل مجهول الهوية
- سياسة خصوصية واضحة
- لا مشاركة للبيانات مع أطراف ثالثة

### 🚀 التثبيت والتشغيل

#### المتطلبات:
- Node.js 18+
- npm أو yarn

#### خطوات التشغيل:

```bash
# 1. استنساخ المشروع
git clone https://github.com/vff7/bloom-clinic.git
cd bloom-clinic

# 2. تثبيت المكتبات
npm install

# 3. تشغيل سيرفر التطوير
npm run dev

# 4. فتح الموقع في المتصفح
# اذهب إلى: http://localhost:3000
```

#### بناء المشروع للإنتاج:

```bash
npm run build
npm start
```

### 📖 دليل الاستخدام

#### للمريض الجديد:

1. **زيارة الموقع** → الصفحة الرئيسية
2. **اختيار "التقييم الذكي"** → سيبدأ الاستبيان
3. **الإجابة على الأسئلة** → اختيار الجنس والعمر و8 أسئلة
4. **الحصول على التوصية** → النظام يقترح الطبيب الأنسب
5. **الموافقة أو الاختيار اليدوي** → حرية كاملة للمريض
6. **حجز الموعد** → ملء البيانات واختيار الوقت
7. **التأكيد** → الحصول على رقم موعد فريد

#### للمريض المتكرر:

1. زيارة الموقع
2. النقر على "حجز موعد" مباشرة
3. اختيار الطبيب والتاريخ والوقت
4. تأكيد الحجز

### 🐛 حل المشاكل الشائعة

#### المشكلة: `npm install` لا يعمل
**الحل:** احذف `node_modules` و `package-lock.json` ثم جرب مرة أخرى
```bash
rm -rf node_modules package-lock.json
npm install
```

#### المشكلة: الموقع لا يفتح على `localhost:3000`
**الحل:** تأكد من عدم استخدام المنفذ من قبل برنامج آخر
```bash
# تغيير المنفذ
npm run dev -- -p 3001
```

#### المشكلة: البيانات لا تُحفظ
**الحل:** تأكد من تفعيل LocalStorage في المتصفح
